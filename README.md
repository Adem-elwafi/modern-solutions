# modern-solutions

> High-Converting, Ultra-Modern Corporate & SaaS Landing Page built with React (Vite), TypeScript, Tailwind CSS, Lucide Icons, and Framer Motion. Features full bilingual localization (English LTR and Modern Standard Arabic RTL).

## 🌟 Key Features

- **Dual-Theme Visual Aesthetic**:
  - **Top Half (Navbar + Hero)**: Deep dark slate/navy backdrop (`#0B1329`), crisp white typography, warm orange CTA buttons (`#F97316`), and organic dark-teal backdrop waves (`#0A3E4B`).
  - **Bottom Half (Content Sections)**: Clean warm off-white canvas (`#FAFAF9`), rich typography, and seamless section transitions.
- **Bilingual & Full RTL Engine**:
  - Dynamic `dir="rtl"` and `lang="ar"` on root DOM.
  - Optical typography pairing: **Plus Jakarta Sans** (English) and **Cairo** (Arabic).
  - Strongly typed translation dictionary with instantaneous language toggle in the Navbar.
  - Directional motion helper (`rtlX`) and mirrored chevrons.
- **"Smooth Modern Sections"**:
  - 12-lobed scalloped rosette ribbon badges (Orange `#F97316`, Teal `#0D9488`, and Accent).
  - High-resolution Retina portrait card with ambient backlight glow.
- **Interactive 3D Bento Accent Cards**:
  - Warm orange, rich teal, and frosted white cards with physics-based 3D tilt.
- **Enterprise Social Proof & Trust Metrics**:
  - Animated scroll-triggered counters (`99.9% Uptime`, `10k+ Teams`, `$12M+ Revenue`).
  - Grayscale-to-color tech partner marquee.
- **Interactive Testimonials**:
  - Category switcher (Enterprise Cloud, FinTech & Banking, High-Growth Tech) with zero layout shift.
- **Conversion & Consultation Form**:
  - Reactive field validation, loading spinner, and instant Google Calendar discovery call reservation state.
- **Corporate Multi-Column Footer**:
  - Real-time operational system status (`🟢 99.99% Operational`) and localized legal links.

## 🚀 Tech Stack

- **Framework**: React 19 + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Plus Jakarta Sans & Cairo

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
